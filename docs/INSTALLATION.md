# Новая установка

Выпуск rc.1 предназначен для проверки на чистом Ubuntu Server 24.04 с systemd.
Поддерживаются x86_64 и arm64. Не запускайте его поверх действующего сайта,
существующего GitRePosted или production-базы. Процесс установки не является
средством восстановления пользовательских данных.

1. Получите полный архив и checksum из одного проверенного выпуска. Сверьте
   checksum до выполнения bootstrap. Отдельный bootstrap.sh без payload не
   устанавливает приложение.
2. Распакуйте комплект в каталог root, недоступный другим пользователям для
   записи. При запуске через sudo файлы, каталог и его родители также должны
   пройти проверку владельца и прав. Не применяйте рекурсивный chmod к системе.
3. Запустите `sudo bash ./bootstrap.sh --public-ip YOUR_PUBLIC_IPV4` из
   распакованного комплекта. Подставьте реальный публичный IPv4 сервера.
4. Дождитесь подготовки HTTPS. Порты 80/443 должны быть доступны для проверки
   адреса и сертификата. Не вводите токены и пароль в HTTP-страницу.
5. Откройте выданную терминалом персональную HTTPS-ссылку `/install/` и
   пройдите мастер. Ссылка даёт доступ к первоначальной настройке; не
   публикуйте её. Отдельно придумывать код доступа не требуется.
6. Задайте логин и отдельный пароль администратора, минимум 12 символов,
   выберите часовой пояс. Подключите Telegram, МАКС, обе платформы или пропустите
   подключение. Для выбранной платформы требуется действительный токен бота.
7. Проверьте токены. Если обнаружен прежний webhook, решите, действительно ли
   нужно перенести этого бота. После подтверждения прежний сервис перестанет
   получать его обновления. Для проверки используйте отдельного бота.
8. При желании настройте hCaptcha. API ID/hash и вход по номеру Telegram не
   требуются. Мастер не разворачивает локальный Telegram Bot API.
9. Запустите финальную настройку. Дождитесь успешного завершения всех этапов;
   только после этого очереди выбранных платформ активируются. Панель
   управления откроется по `/control/`, установка будет закрыта.

Домен необязателен. Для своего домена создайте DNS-запись на адрес сервера и
используйте `--host your-domain.example` при bootstrap либо настройку домена
в мастере. Значения с `YOUR_` и домен `.example` в инструкции — примеры,
которые нужно заменить.

После установки добавьте ботов администраторами нужных тестовых каналов,
запустите диалог с ботом и настройте доступные вашему аккаунту каналы и
маршруты. При двух платформах следуйте процедуре связывания аккаунтов в боте.
Проверьте текст, медиа и отсутствие обратного эха до подключения рабочих
каналов. Права Telegram и МАКС проверяются отдельно.

Если этап завершился ошибкой, сохраните безопасный код ошибки и вернитесь к
тому же мастеру. Не очищайте базу и не удаляйте очереди для повторного запуска.
Не запускайте вторую установку с токеном действующего бота без плана переноса.
