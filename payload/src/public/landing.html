ВОПРОСЫ

Бесплатный постер или автопересылка?

GitRePosted действительно бесплатный?+

Да, исходный код доступен бесплатно по лицензии MIT. При самостоятельной установке нет платы проекту за каждый канал. Сервер вы оплачиваете сами; домен можно подключить по желанию.

Это бесплатная альтернатива Posted / @posted?+

Выбирайте по задаче. GitRePosted нужен для автоматической пересылки уже опубликованных записей. Если вы ищете бесплатный постер для планирования и отложенных публикаций, посмотрите GitPosted. Оба проекта имеют открытый код для самостоятельной установки. Это независимые проекты, а не официальная версия Posted (@posted).

Как добавить свои каналы?+

Добавьте своего бота администратором с правом публикации, затем перешлите ему запись из канала в личный диалог. Ваш аккаунт тоже должен быть владельцем или администратором канала. После проверки канал появится при создании маршрута. Для межплатформенной пересылки свяжите свои аккаунты Telegram и МАКС через меню бота.

Есть ли ограничения по каналам и вложениям?+

Лицензия не предусматривает поканальной платы. Практическая нагрузка зависит от вашего сервера, а размеры файлов, форматы, права и скорость запросов ограничиваются API Telegram и МАКС. Неподдерживаемый формат не превращается автоматически в поддерживаемый.

Где установщик и насколько готов проект?+

Установщик, инструкции и код находятся в репозитории GitHub. Проект находится в предварительном выпуске. Актуальные проверки и ограничения описаны в документе TESTING; свои боты и маршруты сначала проверьте в тестовых каналах.
